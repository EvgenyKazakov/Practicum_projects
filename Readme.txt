Поиск изображений по запросу для фотохостинга «Со Смыслом».
Задача проекта: Разработать модель машинного обучения для предсказания соответствия картинки текстовому запросу.
Исходные данные: датасеты с информацией о фотографиях, запросах и их соответствиях с экспертной оценкой и оценкой краудсорсинга.
Используемые модели:
- LinearRegression
- RidgeRegression
- RandomForestRegressor
- Нейронная сеть
Метрика качества: RMSE.

Лучшая модель в проекте: 
Нейронная сеть

Метрика RMSE на тестовой выборке: 0.2148
