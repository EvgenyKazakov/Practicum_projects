Проект: Разработка модели для предсказания закрытия стартапов.
Задача проекта: Разработать модель машинного обучения для предсказания продолжения деятельности стартапов.
Провести полноценный разведочный анализ и сформировать рекомендации будущим создателям стартапов (какие факторы влияют на успешность стартапа)
Используемые модели:
- KNeighborsClassifier()
- DecisionTreeClassifier()
- SVC()
- LogisticRegression()

Метод подбора лучшей модели: RandomizedSearchCV()
Лучшая модель в проекте: 
DecisionTreeClassifier (max_depth=7, min_samples_leaf=5)

Метрика лучшей модели по кросс-валидации: 0.9347
Метрика ROC-AUC на тестовой выборке: 0.9332
