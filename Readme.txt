Проект: Разработка модели для предсказания повторной покупки клиентом в течение 90 дней.
Задача проекта: Разработать модель машинного обучения для предсказания повторной покупки.
Исходные данные: датасеты с информацией о рекламных рассылках и о покупках клиента.
Используемые модели:
- RandomForestClassifier;
- LGBMClassifier;
- LogisticRegression
Метрика качества: ROC_AUC.
Метод подбора лучшей модели: RandomizedSearchCV()
Лучшая модель в проекте: 
LGBMClassifier(learning_rate=0.05, max_depth=3, n_estimators=200, num_leaves=20, objective='binary', random_state=42, verbose=-1)).

Метрика лучшей модели по кросс-валидации: 0.6596
Метрика ROC-AUC на тестовой выборке: 0.6312
